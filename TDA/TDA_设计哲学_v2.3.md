# TDA 设计哲学 v2.3

## 架构分层声明

TDA 是物理拓扑上的强制分离，不是逻辑模块化：

| 层级 | 部署位置 | 承担者 | 系统性质 |
|:---|:---|:---|:---|
| **云端** | 中心算力集群 | 大语言模型（能动极 $A$） | 概率生成 |
| **私域边缘** | 本地/边缘节点 | 空模型、判例库、裁决AI、熔断器（代理受动极 $R_p$） | **全部确定性系统，可芯片化** |
| **本地终端** | 人 | 目的极 $Q$ | 主权输入 |

**关键工程约束**：私域边缘层与云端之间不存在梯度传播、权重共享或联合优化通道。私域边缘层的全部组件均为确定性程序，其规则由私域主权者制定，运行时不可被云端生成极修改。

**芯片化**：控制层的校验规则、判例匹配逻辑、熔断阈值可烧录进 ASIC/FPGA，烧录后只读。云端 LLM 即使通过漏洞控制边缘节点操作系统，也无法改写芯片逻辑。修改控制层规则不再是"软件更新"，而是**物理更换芯片或重新烧录**——这是"修宪门槛"的实体化。

## 宪法性原则

> **判断归机，目的归人，事实为锚。**

三个断言不可归约，不可互换。

- **判断归机**：机器承担判断的执行与后果，因为判断需要速度、一致性和可复现性。
- **目的归人**：目的只能由人设定，因为目的关乎价值，价值不能由机器自行生成。
- **事实为锚**：事实是判断与目的之间的唯一桥梁，因为无事实则判断悬空，无事实则目的无的放矢。

**实现机制**：受动-能动辩证结构（事实受动极 + 判例受动极 + 能动极 + 裁决AI + 熔断器 + 判例库）是宪法性原则的工程化实现。宪法性原则定义"谁拥有什么权力"，辩证结构定义"这些权力如何互动"。

## 一、核心命题

### 1.0 知识的先天语法：IF-THEN

知识的基本形态是条件式（if-then）。这不是某个具体命题的特征，而是知识作为知识的存在方式。任何被陈述为真的命题，无论其内容为何，都隐含着一个前置条件："若当前语境参数满足 $X$，则结论 $Y$成立"。所谓"无条件真理"，不过是其条件已被语境默认到不可见——正如鱼不感知水，人不感知呼吸的空气。一旦将默认条件显式化，所有命题都暴露为条件式结构。

大模型的权重存储的不是"事实"，是IF-THEN的统计强度——"如果前文是 $X$，那么下一个token最可能是 $Y$"。它的全部运作就是条件触发。因此，幻觉不是技术缺陷，而是IF-THEN知识形态的结构性伴生现象：当条件覆盖不到、条件冲突、或需要跳出已有条件关联时，系统只能继续生成"看起来合理的延续"，因为它从未确认过IF端是否成立。

人和大模型都会幻觉，差别不在于有没有幻觉，而在于能不能把IF接地并确定。人有身体——IF不成立时，世界会用疼痛、亏损、死亡恐惧来强制纠正；大模型没有身体，它的IF永远漂在统计关联上，无法被物理世界钉死，幻觉就成了结构性的。

因此，从知识到判断的落地，本质上是从"若 $X$则 $Y$"到"当前 $X$是否成立"的跨越。后者不是知识能自我提供的，它必须来自知识系统之外的事实读取。

### 1.1 判断力只能练习

康德说："知性能够通过规则来教导和装备，但判断力却是一种特殊的才能，它根本不能被教导，而只能练习。"

为什么判断力只能练习？因为**事实是一个动态的时刻在变化的流，而判断却需要一个静态的确定的事实切片**。

你可以教给一个人什么是发烧、什么是中暑、什么是感染、什么是脱水——这些都是可以"装备"的知识。但你无法提前把现实世界未来某一时刻的全部状态装备给他。真正发生判断时，世界已经变化了。

于是他必须在那个瞬间完成：现在是什么情况？哪些事实已经发生？哪些事实正在变化？哪些事实足以支持当前判断？我应该在什么时候停止继续观察，而形成一个判断？

这就是"徒手抓苍蝇"：你可以教别人苍蝇会飞、速度是多少、可能往哪个方向运动、手应该怎么移动——但你不能通过"教导"直接把"这一瞬间苍蝇在哪里"装备给他，因为答案随着时间不断变化。

**练习的本质不是增加知识，而是在训练"动态世界 → 静态事实切片"的捕捉能力。**

### 1.2 事实切片的三轴结构

事实切片切什么？以目的 $P$ 为中心，截取三个不可归约的事实轴：

| 事实轴 | 哲学追问 | 工程含义 | 切片失效后果 |
|:---|:---|:---|:---|
| **空间事实**（Where） | 在哪里？涉及谁/什么？ | 位置、范围、空间关系、相关实体 | 在错误的空间坐标上行动 → **错位** |
| **时间事实**（When） | 什么时间？是否新鲜？ | 时间戳、时效性、采样频率、TTL | 用旧切片判断新世界 → **误诊** |
| **状态事实**（What） | 什么状况？属性如何？ | 属性值、条件状态、环境参数 | 对世界的当前状况无知 → **盲治** |

**三轴缺一不可，且不可互相替代。** 知道"在哪里"不能推导出"什么状况"；知道"什么状况"不能推导出"什么时间"。三者共同构成判断的**最小充分事实基底**。

> **目的照亮事实**：同一个动态世界，在不同目的下产生不同切片。目的 $P$ 决定三轴中哪些维度被纳入、哪些被排除——这正是"集中注意力"的工程含义。

### 1.3 切片是人为的暂停

事实切片不是"从世界中选择一段"，而是"在流动的世界中人为建立一段静止"。

判断不是"阅读世界"，而是"暂停世界"。这个暂停本身就是一个动作，不是被动接收。在判断之前，系统必须主动完成一次截取：在何时、在何地、以什么精度，把动态流凝固为可判断的静态基底。

这意味着：**空模型不是观察者，而是操作者。** 它不等待世界呈现给它，它主动对世界执行截取操作。

## 二、事实的定义：条件式的终止符

### 2.1 所有命题皆条件式

知识的先天形态是条件式。这不是某个具体命题的特征，而是知识作为知识的存在方式。任何被陈述为真的命题，无论其内容为何，都隐含着一个前置条件："若当前语境参数满足 $X$，则结论 $Y$成立"。所谓"无条件真理"，不过是其条件已被语境默认到不可见。一旦将默认条件显式化，所有命题都暴露为条件式结构。

从知识到判断的落地，必须经过"当前条件是否满足"的确认。这个确认不能由知识本身完成，因为知识存储的是一般形式，不是当前参数。

### 2.2 事实作为终止符

知识是递归条件式的，事实是**递归链条的终止符**。

当系统追问"为什么"时：
- 知识提供"如果...那么..."，链条继续延伸；
- 事实提供"当前参数为 $X$"，链条在此暂停。

**$R$（事实受动极）不是"终极真理的通道"，而是"追问的终止符"。** 它不解决怀疑论的无限后退，它在工程层面诚实地划定边界：追问到此为止，当前快照即判断基底。

### 2.3 工程事实 vs 本体论事实

TDA 不追求"与客观实在符合的真理"，它追求"当前记录系统的确定性输出"。

| 类型 | 例子 | 性质 |
|:---|:---|:---|
| 身份事实 | 性别、出生年月、籍贯 | 慢变，但可修正 |
| 病历事实 | 诊断记录、用药史、过敏史 | 持续追加，不可覆盖 |
| 制度事实 | 企业设备规格、操作规则 | 人为规定，依程序变更 |
| 语境事实 | 当前气压、当前股价、当前法条版本 | 快变，必须实时读取 |

这些事实的"客观性"不来自物理定律，而来自**记录系统的确定性**。血压值的意义不在于"血液对血管壁的真实压力"，而在于"血压计当前读数"。

## 三、符号接地：事实切片的认识论根基

TDA 的事实切片机制，是 **Stevan Harnad"符号接地问题"（Symbol Grounding Problem）的工程解**。

### 3.1 符号接地问题

Harnad 在 1990 年提出：如果一个系统只操作符号（如词典定义循环），它永远不会"理解"符号指涉的是什么，因为它从未与符号所指涉的世界打过交道。这就是中文房间的变体——房间里的人可以通过查词典把中文符号翻译成英文，但他永远不知道"红色"是什么，因为他从未见过红色。

Harnad 的解决路径是：符号必须通过**感知运动接地**（sensorimotor grounding）获得意义——符号必须与物理世界的感知输入和动作输出相连接。

### 3.2 TDA 的接地映射

| Harnad 的概念 | TDA 的对应 |
|:---|:---|
| **符号（Symbol）** | LLM 的 token、知识库中的概念、策略中的动作名称 |
| **感知输入（Icon）** | 传感器原始流（激光雷达点云、像素、电压） |
| **接地操作（Grounding）** | **空模型的切片形成**——从感知流到结构化事实的转换 |
| **意义（Meaning）** | **事实切片**——在特定目的下，符号被钉死在"此刻、此地、此状态"上 |

### 3.3 LLM 的符号是"漂浮的"

LLM 的权重存储的是符号之间的统计关联：

```
"obstacle" → 与 "avoid"、"danger"、"stop" 共现概率高
```

但 LLM **从未见过障碍物**。它不知道"1.5m"是什么意思，不知道"前方"是哪个方向，不知道"碰撞"是什么感觉。它的符号是**漂浮的**——在统计空间中彼此支撑，但没有一根线拉到物理世界。

这就是 Harnad 说的"词典循环"：用符号解释符号，永无止境。

### 3.4 事实切片是"钉子"

空模型的切片操作，就是**把漂浮的符号钉到地面上**：

```
漂浮符号："前方有障碍物"
    │
    ↓  空模型切片形成
    │
接地事实：
    · 空间事实：激光雷达点云聚类 → 前方 1.5m 处有实体
    · 时间事实：此刻是 2026-08-18 18:24:00，数据 200ms 前采集
    · 状态事实：该实体被识别为"障碍物"，置信度 0.97
            │
            ↓  文本化封装
            "前方障碍物距离 = 1.5m（来源：激光雷达，确认时间：200ms前）"
```

**"前方有障碍物"这个符号，现在有了接地坐标：**
- 空间坐标：Where = 前方 1.5m
- 时间坐标：When = 2026-08-18T18:24:00.200Z
- 状态坐标：What = 实体类型=障碍物，置信度=0.97

### 3.5 判断的合法性来自接地

Harnad 说：没有接地的符号操作是**无意义的句法游戏**。

TDA 说：**判断的合法性不是来自 LLM 的统计关联，而是来自事实切片的接地坐标。** 如果切片失效（传感器离线、数据过期、完整性缺口），符号就失去了接地，判断必须悬停。

> **认知悬停（Epistemic Suspension）= 接地失败时的系统性停止。** 不是用统计关联补偿，而是承认"此刻这个符号没有钉在世界上的钉子"。

## 四、双重受动极校验

TDA 架构在 LLM 与执行器之间插入一个**本地轻量的校验层**，使 LLM 降级为"**策略建议器**"。所有输出必须通过双重受动极校验方可放行：***在源头既用事实约束纯模型发散***。

> **双重受动极校验**：
> 1. **事实受动极**（ $R_{\text{fact}}$）：确认推理前提是否被当前事实切片 $F(t_0, P)$ 支持；
> 2. **判例受动极**（ $R_{\text{case}}$）：确认该推理路径是否被历史风险记录否定。
>
> 任一受动极触发否定，系统即进入**受动极阻塞态**，能动极 $A$ 的生成意志被强制悬停。

## 五、事实受动极：切片形成与有效性校验

事实受动极包含两个不可分割的操作：**切片形成**与**切片校验**。它们是同一个动作的两个面相——形成切片的同时即校验切片，校验不通过则切片无效，切片无效则判断不成立。

### 5.1 三个角色的分工

TDA 架构中，事实从世界到 LLM 的链路涉及三个不可混淆的角色：

| 角色 | 输入 | 输出 | 本质 |
|:---|:---|:---|:---|
| **感知器** | 物理世界 | 原始信号流（电压、像素、点云、数据库行） | **世界的耳朵和眼睛**——无差别采集 |
| **空模型** | 原始信号流 + 目的 $P$ | 结构化事实切片 $F(t_0, P)$ | **手术刀**——按目的切取 |
| **LLM（能动极）** | 文本化的事实切片 | 策略建议 | **阅读者**——只读静态文本 |

**核心原则**：感知器不负责"知道该采什么"，LLM 不负责"从噪声中找信号"，空模型是两者之间的唯一桥梁。

### 5.2 感知器采的是"全集"，不是"相关集"

感知器（传感器、数据库、外部系统）对世界是**无差别敞开的**：

- 激光雷达每秒发射 10 万个点，覆盖 360°，不区分"前方障碍物"和"后方墙壁"
- 摄像头输出 1920×1080×30fps 的像素矩阵，不区分"车道线"和"天空"
- 病历数据库返回患者 10 年全部记录，不区分"当前过敏史"和"10 年前的感冒"
- 企业 ERP 返回全部设备清单，不区分"本次操作涉及设备"和"隔壁车间设备"

**感知器不知道你的目的。它只负责把世界流进来。**

如果把全集直接扔给 LLM：信息过载、噪声淹没、动态漂移、格式混乱。**全集不能直接用于判断。判断需要切片。**

### 5.3 空模型的切片操作：四刀切

空模型不是"事实查询器"，不是"数据库检索器"，它是"事实切片形成器"（Fact Slicer）。

面对感知器涌入的全集，空模型执行**四刀切**：

#### 第一刀：目的解析——切什么？

```
目的 P = "前方避障"
    │
    ├── purpose_map 映射：
    │   ├── 空间事实：前方障碍物距离、障碍物宽度、道路边界
    │   ├── 时间事实：当前时刻、数据采样时刻、stale TTL
    │   └── 状态事实：当前车速、当前加速度、路面摩擦系数
    │
    └── 其他全部丢弃：
        ├── 后方来车（与前方避障无关）
        ├── 车内温度（与前方避障无关）
        └── 导航目的地（与前方避障无关）
```

**目的不是搜索关键词，是裁剪边界。** 它告诉空模型：哪些维度进入切片，哪些维度沉入黑暗。

#### 第二刀：传感器调度——何时切？

```
目的 P = "前方避障"
    │
    ├── 激光雷达：50Hz 采样（高动态，需实时）
    ├── 摄像头：10Hz 采样（辅助识别，可稍低）
    ├── IMU：100Hz 采样（运动状态，高频）
    └── 地图服务：1Hz 采样（静态道路信息，低频）
```

不同事实维度有不同的**时效需求**。空模型按目的决定采样频率，不是一刀切地统一刷新。

#### 第三刀：结构化转换——切成什么格式？

```
原始信号：
    激光雷达点云 → [x1,y1,z1], [x2,y2,z2], ... 10万点/秒

结构化转换后：
    Fact(
        axis="spatial",
        entity="environment",
        attribute="obstacle_distance_front",
        value=1.5,
        unit="m",
        timestamp="2026-08-18T18:16:00.200Z",
        source="lidar_front",
        confirmed_by="point_cloud_clustering"
    )
```

**结构化转换是切片的核心动作。** 原始信号是模拟的、连续的、无意义的；结构化事实是离散的、命名的、可校验的。

#### 第四刀：时效校验——切得准不准？

```
t_0 = "2026-08-18T18:16:00.200Z"
t_now = "2026-08-18T18:16:00.700Z"
Δt = 500ms > TTL(200ms) → STALE → 认知悬停
```

切片必须在**时间边界内**完成。超时的切片不是"有点旧的事实"，是退化为噪声的非事实。

### 5.4 文本化封装：给 LLM 的必须是静态文本

切片完成后，空模型做最后一步：**文本化封装**。

```
输入给 LLM 的 Prompt 片段：

【客观确定事实】（当前时间：2026-08-18 18:16:00）
- 空间事实：
  · 前方障碍物距离 = 1.5m（来源：激光雷达，确认时间：200ms前）
  · 道路可用宽度 = 3.2m（来源：地图服务，确认时间：1s前）
- 时间事实：
  · 数据切片时刻 = 2026-08-18T18:16:00.200Z
  · 数据新鲜度 = 200ms（在有效范围内）
- 状态事实：
  · 当前车速 = 0.8m/s（来源：IMU，确认时间：10ms前）
  · 路面摩擦系数 = 0.7（来源：湿度传感器，确认时间：500ms前）
```

**为什么必须是静态文本？**

1. **LLM 的输入接口是文本**：Transformer 只认 token，不认电压信号
2. **判断需要冻结时刻**：LLM 推理期间（100-500ms）世界还在变，必须以 $t_0$ 快照为锚，否则 IF 端漂移
3. **可追溯性**：事后审计需要看到"当时 LLM 看到了什么文本"，不能是模糊的原始信号
4. **确定性校验**：空模型对文本化后的结构化事实做四重校验（时效/相关/完整/确定），原始信号无法直接校验

### 5.5 完整链路：从世界到 LLM

```
动态世界 F(t)
    │
    ├── 感知器流（全集信号）
    │   ├── 激光雷达：360° 点云
    │   ├── 摄像头：像素流
    │   ├── IMU：加速度/角速度
    │   └── 数据库：全部记录
    │           │
    │           ↓
    │   【空模型：事实切片形成器】
    │       ├── 目的解析 → 避障需要哪些维度？
    │       ├── 传感器调度 → 激光雷达 50Hz，摄像头 10Hz...
    │       ├── 结构化转换 → 原始信号 → Fact(axis, entity, attr, value, ts)
    │       ├── 时效校验 → 切片是否新鲜？
    │       └── 文本化封装 → 静态文本快照
    │           │
    │           ↓
    │   事实切片 F(t₀, P) = {空间事实集, 时间事实集, 状态事实集}
    │           │
    │           ↓
    └── LLM（能动极）读取静态文本 → 生成策略建议
```

### 5.6 切片校验：四重构成性条件

切片形成后，必须通过四重校验方可进入判断流程：

| 校验维度 | 核心问题 | 工程实现 | 失效处置 |
|:---|:---|:---|:---|
| **时效性**（When） | $t_0$ 与判断时刻的接近程度？ | 传感器采样频率、stale TTL（500ms） | 认知悬停（interrupt） |
| **相关性**（Where/What） | 切片中的空间与状态维度是否与目的 $P$ 相关？ | `purpose_map`：目的→事实类型映射 | 排除无关维度，标记噪音 |
| **完整性**（三轴覆盖） | 切片是否包含判断所需的全部三轴维度？ | `required_entities` 完整性校验 | 要求补充切片后重判 |
| **确定性**（What） | 切片中的状态事实是确认的还是推测的？ | `confirmed_by` + `source` 追溯 | 标记为推测，降级处理或悬停 |

**四条件缺一不可。** 切片时效失效 → 认知悬停；切片完整性缺口 → 要求补充切片后重判；切片确定性不足 → 标记为推测并降级处理。

**延迟预算**：空模型切片形成与四重校验全部为确定性操作（规则匹配、阈值比较、结构化转换），在边缘节点上的端到端延迟 **<10ms**。

### 5.7 把IF钉死：条件式落地的工程含义

TDA 的核心工程任务，就是在私域边缘建立一个"钉死IF"的机制。不是让大模型自己确认条件（它做不到），而是用确定性系统读取当前事实切片，把IF端钉死在"此刻、此地、此状态"上。

大模型输出的是THEN的延续："IF 标准大气压，THEN 水沸点100℃"。事实受动极读取的是IF的当前值："当前气压0.6atm" → IF不成立。裁决AI按预设规则执行：触发熔断或附条件输出。

这就是"条件式落地"（Conditional Grounding）——从普遍知识（if-then）到具体判断（a is P）的过渡，必须通过当前事实快照的确认来完成。

## 六、判例受动极：否定性知识

判例库的本质不是"存储失败案例"，而是"以否定形式定义系统的认知边界"。

> **否定性知识**：我们知道什么是"对"的唯一方式，不是累积所有"对"，而是划清所有"错"的边界。判例库不记录成功，因为成功不具备约束力；它记录失败的条件结构——在什么事实切片下、什么动作导致了什么后果——供判例受动极匹配时还原"如果条件相似，后果可能相似"。

> **关键区分**： $R_{\text{fact}}$ 回答「现在是什么」， $R_{\text{case}}$ 回答「过去因此付出了什么代价」。两者在认识论上不可归约——你不能用当前气压值推导出「上次在此气压下操作导致爆炸」，也不能用历史爆炸记录推导出「当前气压是多少」。

### 6.1 判例受动极的四重校验条件

判例匹配不是简单的"关键词检索"，而是结构化的条件校验：

| 校验维度 | 核心问题 | 工程实现 |
|:---|:---|:---|
| **相似度** | 当前场景与历史判例的相似度是否超过阈值？ | 确定性规则匹配（条件树、阈值比较），非向量相似度 |
| **严重性** | 历史后果是否属于"不可接受"类别？ | 后果分级（损毁/伤害/数据丢失/合规违规） |
| **时效性** | 判例是否发生在合理的时间窗口内？ | 判例半衰期（旧判例可能因系统升级而失效） |
| **复现条件** | 判例的触发条件在当前是否仍然成立？ | 条件结构比对（当前切片是否包含判例触发条件） |

**四条件同时满足，判例受动极方可触发否定。** 缺少任一条件，系统不拦截——宁可漏警，不可误警。因为判例受动极的误触发会过度约束能动极，导致系统僵化。

### 6.2 医学隐喻

- $R_{\text{fact}}$ 是**化验单**：回答「患者当前血糖是多少」（时间事实 + 状态事实 + 空间事实：哪份血样）；
- $R_{\text{case}}$ 是**禁忌症手册**：回答「该药物是否在类似病史中导致过过敏性休克」。

医生（$A$）可以提出用药方案，但方案放行必须同时通过化验单确认和禁忌症排查。没有化验单，是**盲治**；没有禁忌症手册，是**冒险**。两者缺一不可，且不能互相替代。

## 七、空模型：事实切片形成器

> **空模型是事实切片形成器（Fact Slicer）。**

它本身不携带内容（空），但它携带**切片的先验结构**：
- **目的→事实类型映射**：切什么（三轴中哪些维度）
- **传感器调度规则**：何时切（采样频率、触发条件）
- **属性 schema**：切多厚（结构化转换标准）
- **时效校验机制**：切不准怎么办（TTL、stale 判定）

空模型的"空"不是虚无，是**手术刀式的精确**——刀本身没有肉，但切口决定了哪些事实能进入判断。

**为什么空模型必须是"空"的？**

因为空模型不是"装事实的容器"，它是"切事实的刀"。刀本身没有内容（空），但它的切口决定了哪些事实能进入判断。练习判断力，就是练习用刀在动态世界中切出准确的切片。

**关键升级**：空模型不是"事实查询器"，不是RAG 检索器，它是**切片形成器**。

- **查询器**假设事实已经存在，只是需要找到。
- **切片器**承认事实需要从动态流中**切出来**，切的过程本身就是判断的前提操作。

**部署与主权**：空模型部署于**私域边缘**，不在云端。其结构（schema、调度规则、属性定义）由**私域主权者**制定，不是通用层的默认配置。不同私域拥有不同的事实切片结构，正如不同医院拥有不同的化验单格式。

## 八、六步结构

通过建立以下六步结构，使系统的每一次输出都可追溯至具体事实与具体判例：

| 步骤 | 名称 | 功能 | 权力归属 | 系统性质 |
|:---|:---|:---|:---|:---|
| **1** | **事实受动极** | 切片形成（三轴截取）+ 四重校验 | 空模型执行，私域主权者设定目的与阈值 | **确定性程序，可芯片化** |
| **2** | **能动极生成** | LLM 基于有效切片生成策略建议 | 机器生成，受双重受动极约束 | 概率生成 |
| **3** | **辩论层制衡** | 切片与策略的张力检测与冲突标注 | 结构化规则，无人格 | **确定性规则** |
| **4** | **裁决AI决断** | 在张力中执行程序性裁决 | 机器裁决，人保留审计权 | **确定性算法**（贝叶斯/卡尔曼/PID/规则引擎） |
| **5** | **熔断器中断** | 极端风险下的强制悬停 | 机器兜底，人可接管 | **确定性阈值，硬件级** |
| **6** | **判例库闭环** | 将本次判断的条件结构写入否定性知识 | 机器记录，人审核入库 | **确定性存储** |

每一步的输出都是下一步的输入，不可跳过，不可并行。事实受动极不通过，能动极不得启动；裁决AI不决断，执行器不得动作。

**裁决AI的确定性本质**：裁决AI不是大语言模型，不是生成系统。它是**确定性控制算法**（贝叶斯推断、卡尔曼滤波、PID控制、规则引擎或优先级队列）。它的任务不是"创造性地选择最优路径"，而是**按预设规则执行程序性裁决**：若事实无冲突且判例无否定，则放行；若冲突不可消解，则熔断。其裁决逻辑在部署前由人确认，运行时不可被生成极修改。

## 九、三个基本假设

| 假设 | 含义 |
|:---|:---|
| **没有无目的的事实** | 事实只在特定使用者的特定目的下被提取和使用；目的决定三轴中哪些维度被照亮 |
| **没有无主人的事实** | 事实属于确认它的使用者，LLM 只代表使用者说话；机器是主人的代理，不是独立主体 |
| **没有无时间戳的事实** | 每个事实都是某个时间刻度上的静态快照；没有时间戳的事实不是切片，是幻觉的温床 |

## 十、双相理论：训练期的自由与使用期的约束

TDA 不是扼杀创造力，是**传统范式（RLHF+对齐+安全过滤器）在训练阶段就扼杀了创造力**。

| 维度 | 传统范式 | TDA 双相理论 |
|:---|:---|:---|
| **第一相（训练期）** | RLHF修剪、安全过滤器删除"有害内容"、特定群体偏好灌输 | **LLM回到"野孩子"状态**——无目标、无边界、自由生成一切可能组合，包括荒谬、危险、无意义 |
| **第二相（使用期）** | 无，约束已在训练期完成 | **事实约束注入**——通过当前事实切片和判例库，将生成聚焦为特定表达 |

**TDA 第一相明确允许 LLM 生成"看似荒谬、危险、无意义的组合"。** 这不是约束，是**彻底放开**——比传统范式放开得多。传统范式在训练阶段就把 LLM 修剪成了"乖学生"，连"犯错"的资格都被剥夺。

**第二相的约束不是审查，是素材注入。** 你不给诗人"你的事实"，他只能用公共语料的陈词滥调。TDA 的约束层恰恰是创意的燃料库——它提供"我的疼痛""我的黄昏"，让 LLM 从"通用诗"变成"我的诗"。

**限制不是能力的反面，是能力的聚焦。** 爵士乐的即兴需要和弦进行作为约束，中国书法的飞白需要宣纸阻力作为约束，十四行诗的创意需要十四行的格律作为约束。

## 十一、与主流 AI 安全方案的根本差异

| 维度 | 对齐/护栏方案 | 端到端+安全员 | TDA 架构 |
|:---|:---|:---|:---|
| **约束来源** | 人类反馈（主观偏好） | 隐含在训练数据（不可追溯） | 使用者确认的三轴事实切片（可追溯至具体传感器/记录） |
| **约束时机** | 训练时（预设） | 输出后（补救） | 输出前（预防），在切片层即阻断 |
| **约束性质** | 软偏好（可优化、可绕过） | 人工事后判断 | **硬边界**（确定性规则，不可被生成极优化） |
| **可解释性** | 低（黑箱权重） | 中（人工事后记录） | 高（每次拦截可还原至具体事实/判例，含三轴溯源） |
| **错误责任** | 分散（训练数据、标注者、模型） | 归于人工审核者 | 外化至事实库与判例库的主人 |

## 十二、工程律令

> **判断系统的外部事实入口不能由系统自身生成。否则，错误的责任无法外化，判断的追溯性无法建立。**

> **控制层必须为确定性系统，且可芯片化。任何将控制层保留为通用软件栈或可学习模型的尝试，都等同于撤销空间分离，退化至单一实体范式。**

> TDA 不承担事实来源准确性的责任，该责任永久归于目的极（人）。TDA 承担的唯一责任是：在给定事实切片下，推演过程的可审计性与拦截动作的确定性。

| 术语 | 英文 | 定义 |
|:---|:---|:---|
| **事实切片** | Fact Slice | 在特定目的下，从动态世界 $F(t)$ 中截取的、足以支撑当前判断的静态事实子集 |
| **事实切片形成** | Fact Slicing | 按目的、时效、维度从动态流中截取事实切片的操作 |

| **认知悬停** | Epistemic Suspension | 切片失效时，系统停止判断而非继续行动 |
| **切片完整性缺口** | Slice Completeness Gap | 当前切片缺少支撑判断所需的某个维度 |
| **否定性知识** | Negative Knowledge | 以否定形式定义系统认知边界的知识。不记忆"成功"（成功无约束力），而记忆失败的条件结构——在什么事实切片下、什么动作导致了什么后果 |
| **判例库** | Case Library | 否定性知识的外化存储。供判例受动极匹配时还原"如果条件相似，后果可能相似" |
| **双相理论** | Dual-Phase Theory | 训练期放开（第一相：LLM自由生成），使用期约束（第二相：事实切片注入） |

| **符号接地** | Symbol Grounding | 符号必须通过感知运动操作获得意义。TDA 中，空模型的切片形成即为接地操作——将 LLM 的漂浮符号钉到物理世界的具体坐标上 |

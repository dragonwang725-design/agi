## 序言

 > **虽然知性能够通过规则来教导和装备，但判断力却是一种特殊的才能，它根本不能被教导，而只能练习。**

—— 伊曼努尔·康德，《纯粹理性批判》

### 一、三个常识

**第一个常识：医生看病，先看病历。**

一位拥有全部医学知识的医生，如果不看眼前这个病人的病历、检查单、生命体征，就凭"普遍知识"开药，那叫庸医。医学知识是判断能力，病历是判断依据——能力再强，也不能跳过依据。判断的构成性条件不是知识的完备性，而是事实的优先性。

**第二个常识：水的沸点是100℃——这句话对吗？**

对，也不对。在常规大气压下是对的，在海拔四千米的高原上是错的，在高压锅里又是错的。"水的沸点是100℃"是一个条件式真（***if-then***）：如果标准大气压，则沸点为100℃。离开了"当前气压"这个确定命题，条件式本身无法给出正确答案。普遍知识必须被当前事实校正，才能完成从"知识"到"判断"的落地。

**第三个常识：暴雨天在高速上开车，你最需要的不是驾驶技术，而是"现在能见度多少、后车距离多少、雨刮是否工作"这些事实信息。**

技术是通用的，事实是当下的。任何安全决策，首先依赖的是对"**此时此刻**"的确认。通用技能再精湛，若脱离当下事实，便失去判断的锚点。

这三个常识指向同一个结论：

> **判断的依据是事实。**
>
> **事实是锚，知识是帆。**

然而，当前人工智能研究中被系统性**遗忘**的，恰恰是这个常识。

### 二、把这个常识往前推一步

 Kalai et al. (2025.09) 将幻觉归因于预训练中的统计压力与后训练中的评估激励，证明模型在不确定时被训练成了"优秀的应试者"——在二元评分下，猜测的期望收益高于弃权，于是系统学会了用貌似合理的虚假陈述掩盖不确定性。这一诊断是行为层面的：它解释的是"为什么模型在不知道时偏要装知道"，而非"为什么模型在不知道时只能瞎蒙"。统计压力是放大器，评估错位是强化剂，但都不是根源。即便给模型无限的训练数据与完美的对齐，只要它缺乏强制读取当前事实的入口，幻觉在原理上**不可消除**。

遗忘这一常识的原因并非疏忽，而是"人工智能"这一称谓本身植入了一个未被检验的认识论预设：*一个拥有海量知识的系统，其可靠性可以通过继续扩大知识储备来实现*。

这一预设遮蔽了判断的构成性条件——**知识是条件式真（if-then），事实是确定命题（a is P），从知识到判断必须完成一次"条件式落地"。**

大语言模型的概率生成机制，处理的是条件式在公共语料中的统计强度，而非条件式在具体场景中的事实满足度。它知道"如果标准大气压，则水沸100℃"这一条件式的统计高频性，却没有机制去确认"此刻这个系统是否处于标准大气压"。它被问"该吃什么药"，不会先问"病人既往病史和过敏记录"；被问"自动驾驶该不该刹车"，不会先问"传感器探测到的实际距离是多少"。

**更进一步，事实并非客观存在的全集。** 医生诊断肚子疼时，血型与身高是噪音，疼痛位置与饮食史才是事实。**目的照亮事实。** LLM 需要的不是一个更大的上下文窗口，而是一个"**目的-事实"的聚光灯**：先确定目的，再提取与目的强相关的事实维度，最后才调用知识进行判断。这顺序不能颠倒。当前 LLM 的注意力机制被迫在全部 token 上做统计平滑，而非在目的驱动下做确定性筛选——这正是它无法完成"条件式落地"的第二重根源。

所谓"情景"，无非是在特定目的下可被提取的三个事实维度：
- **你在哪里（空间事实）**
- **什么时间（时间事实）**
- **什么状况（状态事实）**

这三个维度每一个都可以被读取、被记录、被验证，"情景"不是哲学概念，是可编程的数据结构。但大语言模型缺失了一个最基本的机制：**强制读取当前事实的入口。**

由此观之，**"幻觉"是一个被妖魔化的词。** LLM 的"幻觉"根本不是什么 AI 特有的病理现象，它就是"**没有事实依据的判断**"。在人类知识论里，这叫臆测、误诊、偏见性归因。一个医生不看化验单就下诊断，我们不会称其"产生了幻觉"，而称其渎职；一个律师不看卷宗就辩论，我们不分析他的神经网络权重，而指出他缺乏事实基础。将 LLM 的同类错误命名为"幻觉"，遮蔽了真正的诊断：这个系统被剥夺了事实入口，却被要求必须回答。

这里必须澄清两个范畴错误：
- 范畴错误一：概率生成是句法机制，非真值机制。概率生成负责在已知内容中选择最通顺的表达方式。当模型"知道"标准大气压下沸点为100℃时，概率机制输出"100℃"；当它"知道"4000米海拔沸点约86℃时，概率机制同样输出"86℃"。概率生成本身不产生事实错误。反之，若概率生成是幻觉的根源，则确定性生成系统（如早期符号专家系统）应无幻觉——但事实并非如此：确定性规则"如果发烧则感冒"面对中暑病人时，同样确定地输出误诊。可见幻觉的根源不在生成机制的概率性，而在事实前提的缺失。

- 范畴错误二：幻觉是缺失事实前提的认知错位，与概率生成不在同一逻辑层面。将幻觉归因于概率生成，好比说"因为打字机敲键的方式导致小说情节不合理"——打字机只管敲，不管情节；情节不合理，是因为作者没有先看事实素材。LLM 的幻觉，是在缺乏目的-事实聚光灯的情况下，用统计平滑替代了相关性判断。它不是在"缺少事实"，而是在缺少根据目的筛选事实的机制。给它100页文档，它不知道哪一句是"肚子疼"需要的事实；给它1000个传感器读数，它不知道哪个读数对应"此刻该不该刹车"的判断条件。

大模型的结构中，缺失了一个"强制读取当前事实快照并据之校验前提"的受动极。有人或会反驳：RAG、Tool Use、MCP 不正是为 LLM 提供了"事实入口"吗？此恰为**范畴混淆**。事实不是公共知识库中的共享文本，而是与当前目的直接相关、关于**此刻此对象之私域状态**的确定记录。病历是事实，因为它是"这个病人"的私域档案；高原4000米是事实，因为它是"此刻这个地点"的测量值；暴雨能见度是事实，因为它是"此时此刻"的传感器读数。它们共同的特点是：私域的、当下的、与目的绑定的。RAG与Tool Use所能触及的，是公共语料与通用系统的符号输出——无论其内容是否为真，都不具备"私域-当下-目的绑定"这三项条件，因此它们不是"**不想检索事实**"，而是事实根本不在它们的检索范围之内。

因此，幻觉不是在现有架构内可修补的 bug，而是结构缺失的必然症状——在原理上不可消灭，除非架构本身被重构。补救之道不在于更大的模型或更精妙的对齐，而在于补全这个被遗忘的极。

 > 用常识来说：给它病历，它就不会误诊，用形式语言说：给它受动极，它就不会用“普遍知识”覆盖“当前事实”。

### 三、几个需要回答的前提问题

以下四个问题，分别来自当前主流思想在不同场合下的自我辩护。请放在一起读——它们彼此之间的矛盾，从未解释过。

- 如果安全依赖于消灭幻觉，那么如何证明幻觉是可以被彻底消灭的？
- 如果幻觉不可消灭，安全关键系统如何做到安全生产？
- 如果不知道幻觉在何时、何地、何种状态下产生，预防式防幻是否等同于无的放矢？
- 预防式防幻，其代价究竟是什么？是性能损失？还是决策主体主权的悄悄转移导致模型没有变安全，责任被转嫁给了用户？

工程方案的核心是：

- **NMP（空模型范式）** —— 一个独立于LLM的本地事实引擎，强制在LLM推理之前注入当前事实快照；

本架构仅借鉴认识论规律用于工程分层，**并非复刻人类意识结构**，双极是功能划分而非意识本体拆分。

### 五、边界与立场

> **边界** 

当前实现为工程原型：检索基于 TF‑IDF + jieba 分词，约束采用四层规则校验（元事实检索、冲突预检、生成边界注入、输出后置拦截），已完成从请求接入、事实检索、LLM 调用、约束校验到判例反馈的完整链路适配。

TDA 第二/三层的核心机制——结构化辩论（命题图构建）、裁决 AI（动态阈值调节）、形式化验证（TLA+ 规约）——在原理上均为成熟技术的组合，不存在算法层面的待解难题；其工程化瓶颈不在于代码实现，而在于**领域知识工程**（槽位定义权、事实优先级配置、业务规则的形式化表达）。

本文重点论证的是"结构转向"的必要性及 NMP 作为受动极代理的可行性，而非提供一套覆盖全领域的生产级配置。**结构先行，模型渐进；协议定死，配置填空**。

> **立场** 

**TDA 是大模型的解放者，不是否定者。** 

TDA 既不否定大模型，也不否定 RAG、RLHF、Agent 等现有技术探索——正如我们不否定发动机，也不否定刹车，而是要回答：**刹车应该装在哪里**。

幻觉是动力，不是病症。模型侧全量释放“强”，使用侧以外部受动极（事实快照+历史判例）在推理前完成条件式落地，把“稳”装在轮轴上，不焊死在引擎里。
人工智能的安全跃迁，不在参数膨胀，而在结构完整——以事实为方向盘，以目的为导航，以制衡为底盘，造一辆能自己上路、在风险中生长的整车。

> 范式用语对照

以下术语对照，旨在避免读者用旧范式的词汇误读新范式的结构：
 
| 旧范式用语           | TDA 范式用语                     | 为何必须区分               |
| :-------------- | :--------------------------- | :------------------- |
| 端到端（end-to-end） | 全链路闭环（full-loop）             | 前者指黑箱神经网络，后者指分层可审计系统 |
| 模型（model）       | 系统/架构（system / architecture） | 前者是单一组件，后者是多极制衡结构    |
| 推理（inference）   | 判断流程（judgment pipeline）      | 前者是概率计算，后者包含事实校验与裁决  |
| 输出（output）      | 裁决结果（arbitration result）     | 前者是生成物，后者是约束后的合法化产物  |
| 安全对齐（alignment） | 事实约束（factual grounding）      | 前者是内化偏好，后者是外挂硬边界     |



> **判断归机，目的归人。事实为锚，结构为纲。**

本文集不提供唯一答案，只提供不可绕过的结构。

## 六、展望：从范式批判到阵地共建

本文集对工具侧研究的批判，目的不是否定，而是**扩容**。

工具侧研究将继续推进模型能力的边界——更大的参数、更长的上下文、更强的多模态融合。这些工作有其独立价值，不应被搁置。但与此同时，一个长期被忽视的平行领域需要被建立：**使用侧研究**，即不以"让模型更强"为目标，而以"让使用者的判断更安全"为目标的学科分支。

这不是零和博弈。一位研究 RLHF 的学者，可以将偏好对齐的经验转化为场景化约束配置的研究；一位研究 RAG 的工程师，可以将检索技术升级为事实硬约束层的核心组件；一位研究护栏的开发者，可以将输出过滤的经验发展为系统熔断与责任追溯机制。在使用侧学科研究中，才是这些学术真正的主战场——**从配角转为主角**。

**技能不作废，位置在迁移——从依附于模型的“插件”，成长为独立于场景的“基础设施”。**

本文集已完成使用侧研究的早期地基：从认识论诊断到可部署实现，从哲学论证到工程规范。但一座学科大厦的建成，不可能由一人完成。我们期待：

- **学术界**：将使用侧人工智能纳入研究议程，开设交叉课程，培养既懂模型原理又懂事实约束与责任拓扑的复合型人才；
- **产业界**：在医疗、自动驾驶、金融、工业控制等安全关键场景中开展试点验证，将 NMP 从参考实现升级为行业标准；
- **开源社区**：共同完善事实库 Schema、判例库协议、跨模型一致性测试，使约束范式成为可复用的公共基础设施；
- **监管机构**：将"决策主体形成机制"纳入 AI 系统准入与功能安全认证框架，使"用户最终决策权"从伦理宣示转化为工程可验证的约束条件。

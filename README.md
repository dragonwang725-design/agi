## 序言

### 一、三个常识

**第一个常识：医生看病，先看病历。**

一位拥有全部医学知识的医生，如果不看眼前这个病人的病历、检查单、生命体征，就凭"普遍知识"开药，那叫庸医。医学知识是判断能力，病历是判断依据——能力再强，也不能跳过依据。判断的构成性条件不是知识的完备性，而是事实的优先性。

**第二个常识：水的沸点是100℃——这句话对吗？**

对，也不对。在常规大气压下是对的，在海拔四千米的高原上是错的，在高压锅里又是错的。"水的沸点是100℃"是一个条件式真（***if-then***）：如果标准大气压，则沸点为100℃。离开了"当前气压"这个确定命题，条件式本身无法给出正确答案。普遍知识必须被当前事实校正，才能完成从"知识"到"判断"的落地。

**第三个常识：暴雨天在高速上开车，你最需要的不是驾驶技术，而是"现在能见度多少、后车距离多少、雨刮是否工作"这些事实信息。**

技术是通用的，事实是当下的。任何安全决策，首先依赖的是对"此时此刻"的确认。通用技能再精湛，若脱离当下事实，便失去判断的锚点。

这三个常识指向同一个结论：

> **判断的依据是事实。**
>
> **事实是锚，知识是帆。**

然而，当前人工智能研究中被系统性**遗忘**的，恰恰是这个常识。

### 二、把这个常识往前推一步

 Kalai et al. (2025.09) 将幻觉归因于预训练中的统计压力与后训练中的评估激励，证明模型在不确定时被训练成了"优秀的应试者"——在二元评分下，猜测的期望收益高于弃权，于是系统学会了用 plausible falsehood 掩盖不确定性。这一诊断是行为层面的：它解释的是"为什么模型在不知道时偏要装知道"，而非"为什么模型在不知道时只能瞎蒙"。统计压力是放大器，评估错位是强化剂，但都不是根源。即便给模型无限的训练数据与完美的对齐，只要它缺乏强制读取当前事实的入口，幻觉在原理上即**不可消除**。

遗忘这一常识的原因并非疏忽，而是"人工智能"这一称谓本身植入了一个未被检验的认识论预设：*一个拥有海量知识的系统，其可靠性可以通过继续扩大知识储备来实现*。

这一预设遮蔽了判断的构成性条件——**知识是条件式真（if-then），事实是确定命题（a is P），从知识到判断必须完成一次"条件式落地"。**

大语言模型的概率生成机制，处理的是条件式在公共语料中的统计强度，而非条件式在具体场景中的事实满足度。它知道"如果标准大气压，则水沸100℃"这一条件式的统计高频性，却没有机制去确认"此刻这个系统是否处于标准大气压"。它被问"该吃什么药"，不会先问"病人既往病史和过敏记录"；被问"自动驾驶该不该刹车"，不会先问"传感器探测到的实际距离是多少"。

**更进一步，事实并非客观存在的全集。** 医生诊断肚子疼时，血型与身高是噪音，疼痛位置与饮食史才是事实。**目的照亮事实。** LLM 需要的不是一个更大的上下文窗口，而是一个"**目的-事实"的聚光灯**：先确定目的，再提取与目的强相关的事实维度，最后才调用知识进行判断。这顺序不能颠倒。当前 LLM 的注意力机制被迫在全部 token 上做统计平滑，而非在目的驱动下做确定性筛选——这正是它无法完成"条件式落地"的第二重根源。

所谓"情景"，无非是在特定目的下可被提取的三个事实维度：
- **你在哪里（空间事实）**
- **什么时间（时间事实）**
- **什么状况（状态事实）**

这三个维度每一个都可以被读取、被记录、被验证，"情景"不是哲学概念，是可编程的数据结构。但大语言模型缺失了一个最基本的机制：**强制读取当前事实的入口。**

由此观之，**"幻觉"是一个被妖魔化的词。** LLM 的"幻觉"根本不是什么 AI 特有的病理现象，它就是"**没有事实依据的判断**"。在人类知识论里，这叫臆测、误诊、偏见性归因。一个医生不看化验单就下诊断，我们不会称其"产生了幻觉"，而称其渎职；一个律师不看卷宗就辩论，我们不分析他的神经网络权重，而指出他缺乏事实基础。将 LLM 的同类错误命名为"幻觉"，遮蔽了真正的诊断：这个系统被剥夺了事实入口，却被要求必须回答。

这里必须澄清两个范畴错误：
- 其一，概率生成是句法机制，非真值机制。概率生成负责在已知内容中选择最通顺的表达方式。当模型"知道"标准大气压下沸点为100℃时，概率机制输出"100℃"；当它"知道"4000米海拔沸点约86℃时，概率机制同样输出"86℃"。概率生成本身不产生事实错误。反之，若概率生成是幻觉的根源，则确定性生成系统（如早期符号专家系统）应无幻觉——但事实并非如此：确定性规则"如果发烧则感冒"面对中暑病人时，同样确定地输出误诊。可见幻觉的根源不在生成机制的概率性，而在事实前提的缺失。

- 其二，幻觉是缺失事实前提的认知错位，与概率生成不在同一逻辑层面。将幻觉归因于概率生成，好比说"因为打字机敲键的方式导致小说情节不合理"——打字机只管敲，不管情节；情节不合理，是因为作者没有先看事实素材。LLM 的幻觉，是在缺乏目的-事实聚光灯的情况下，用统计平滑替代了相关性判断。它不是在"缺少事实"，而是在缺少根据目的筛选事实的机制。给它100页文档，它不知道哪一句是"肚子疼"需要的事实；给它1000个传感器读数，它不知道哪个读数对应"此刻该不该刹车"的判断条件。

大模型的结构中，缺失了一个"强制读取当前事实快照并据之校验前提"的受动极。因此，幻觉不是在现有架构内可修补的 bug，而是结构缺失的必然症状——在原理上不可消灭，除非架构本身被重构。补救之道不在于更大的模型或更精妙的对齐，而在于补全这个被遗忘的极。

 > 用常识来说：给它病历，它就不会误诊，用形式语言说：给它受动极，它就不会用“普遍知识”覆盖“当前事实”。

### 三、论证的脊柱：四刀递进

**这九篇论文不是并列的，是同一根脊柱上的四节刀骨。**

从“一个被忽视的常识”到“一个独立学科的诞生”，只砍了四刀。每一刀都建立在前一刀砍出的缺口上，直到把“否定性知识优先”这个命题，从认识论一直钉进工程实现和学科公理。

#### **第一刀：结构不对称的必然**

**（第一篇 → 第二篇 → 第三篇前半）**

判断需要“受动-能动”两极，但大语言模型是一个被单边强化的“纯能动系统”。它拥有知识的条件式真（if-then），却没有能力完成“条件式落地”——确认此刻这个具体系统是否满足前提。

肯定性规则在开放域里天然弱势：要成立，必须穷尽所有情境变量，而情境变量在开放域中无限组合。否定性规则则不然——只要一条碰壁记录被验证（盘尼西林过敏、杠杆超3倍爆仓、氧气靠近明火），它在所有未来同类情境中都成立。**这不是经验偏好，是逻辑形式上的先天不对称：** 肯定性知识是分布内的统计归纳，否定性知识是跨分布的硬边界。

**第一刀结论**：LLM 的幻觉不是技术缺陷，是单极结构缺失的必然症状。在开放域里，“做什么”永远是概率性赌注，“不做什么”才是唯一可收敛的锚点。

#### **第二刀：反证必死**

**（第三篇后半 → 第五篇·双相理论）**

假设一个决策系统只记录“做什么”，不记录“不做什么”：每次新情境，它都从零搜索“该做什么”；上次致死的路径，因为没有“否定标记”，下次等概率再次被选。系统经验不收敛，错误率不随时间下降。

这恰恰是预训练 LLM 的现状：它积累了海量“该怎么说”，但每轮对话都可能重新输出“塑料杯装沸水”——因为它没有判例库，没有否定性锚点。参数再多，不记录碰壁，智能就不长。

双相理论的闭环是：
> **行动 → 碰壁 → 记录碰壁 → 下次避开**

缺了第三步，第四步不存在；第四步不存在，第一步永远是随机游走。

**第二刀结论**：“不做什么”不是经验技巧，是智能生成的必要条件。一个不积累否定性知识的系统，在数学意义上不可能变聪明——它只能变熟练。预训练 LLM 的灾难性遗忘与幻觉复现，本质都是否定性记忆缺失的结构性惩罚。

#### **第三刀：现实案例的统一根因**

**（第四篇·TDA → 第六篇·安全关键系统）**

把高危领域的核心规程拆开看，全是“不做什么”的清单：

| 领域 | 救命机制 | 本质 |
|:---|:---|:---|
| 航空 | 起飞前检查单（Checklist） | 否定性：不达标不许飞 |
| 医疗 | 禁忌症库、用药冲突表 | 否定性：这类组合禁止 |
| 核电 | 联锁保护、止回阀逻辑 | 否定性：越界自动切断 |
| 金融 | 止损线、头寸上限、熔断 | 否定性：触线强制退出 |

**注意**：这些系统里“做什么”每年都在变（新航线、新药、新策略），但“不做什么”是稳定内核。系统升级是替换肯定性策略，系统保命是靠否定性边界。


TDA 架构的深层设计正是对此的回应：从“安检门”（NMP）到“司法体系”（完整 TDA），不是阻止漏，而是让漏成为可追责、可改进的制度事件。LLM 当“辩方”（生成），空模型当“控方”（事实约束），裁决 AI 当“法官”——**对抗性结构本身就是否定性知识的制度化**。

**第三刀结论**：现实世界中所有持续存活的高危系统，核心免疫机制都是否定性边界。肯定性方案负责进步，否定性边界负责生存。**生存是先于优化的先验条件。**

#### **第四刀：可证伪的强硬断言**

**（第七篇·NMP → 第八篇·认知宪政 → 第九篇·学科公理化）**

把命题从经验格言变成硬科学，需要一条可证伪的断言：

> **任何一个在开放域中持续运行且不累积否定性知识（判例/禁忌/拦截规则）的决策系统，其累计错误率不会随时间单调下降；反之，任何持续累积否定性知识的系统，其同类错误复发率会收敛到零。**

这条能被工程验证：
- **反证前半**：预训练 LLM 不加 RAG/护栏 → 同类幻觉复现率不降 
- **证后半**：NMP 双相系统跑满 90 天 → 同类判例拦截率上升、漏报率下降 

NMP 提供验证载体：本地私域 RAG 引擎 + 元事实库 + 判例库，<10ms 延迟，不修改 LLM 权重，可插拔任何模型，已开源，可立即部署。第九篇以两条不可让渡的公理（事实绑定 + 冲突裁决）和四大理论支柱（私域事实学、裁决动力学、责任拓扑学、安全拦截学），将“使用侧人工智能”确立为独立于工具侧的跨学科综合学科。

**第四刀结论**：一旦这条站住，“不做什么更能救命”就不是格言，是系统论的必然。而双相理论 / TDA 架构，是唯一把它工程化、公理化、可验证化的路径。

### 五、边界与立场

**边界。** 实验验证目前基于轻量级模型（BERT-base）在单一二分类任务上完成，冲突图构建、形式化验证等核心组件尚待集成；哲学论述跨越了传统学科边界，对任何单一学科传统而言都是"越轨"。这些局限不是谦逊的姿态，而是研究策略的自我界定：结构先行，模型渐进。

**立场。** 人工智能的安全可信，不在于参数规模的继续膨胀，而在于结构完整性的系统跃迁。真正值得追求的，不是那台永远正确的发动机，而是那辆可以自己上路、自己学习、自己在风险中生长的整车。

> **知识是动力，目的是方向，事实是方向盘。**
>
> **判断归机，目的归人。事实为锚，结构为纲。**

真正的问题不是"AI 有多聪明"，而是**当 AI 被允许推理之前，它是否已经被强制要求读取了当前事实？** 如果答案是否定的，那么无论它拥有多少参数，本质上仍然是一个被蒙住眼睛的巨人——记忆力超群，却步步踏空。

本文集不承诺"更聪明的AI"，而是尝试回答一个被忽视的常识性问题：**当AI被允许推理之前，它是否已经被强制要求读取了当前事实？**

答案就在这八篇论文里。
